# Complete Timeline

## Broadcast Era (1995-2000)

### 1995

| Date | Event |
|------|-------|
| April 23 | BS-X cartridge and Satellaview service launch[^1] |
| April 23 | Tamori no Picross broadcast begins (per Jupiter Corp; disputed by SFC Mania which found evidence of earlier April 23 broadcast)[^2] |
| May-June | Initial SoundLink broadcasts begin |
| August 6 | Tamori no Picross official broadcast window (per Jupiter Corp)[^3] |
| September 2 | Tamori no Picross official broadcast end[^3] |

### 1996

| Date | Event |
|------|-------|
| 1996 | BS Zelda no Densetsu Map 1 ("Third Quest") broadcast -- dungeon names spell "St.GIGA"[^4] |
| 1996 | BS Zelda no Densetsu Map 2 ("Fourth Quest") broadcast -- dungeon names spell "NiNtENDO"[^4] |

### 1997

| Date | Event |
|------|-------|
| September 28 | BS Fire Emblem: Akaneia Senki Episode 1 "Pales shugeki" broadcast[^5] |
| October 5 | BS Fire Emblem: Akaneia Senki Episode 2 "Akai kaze RON" broadcast[^5] |
| October 12 | BS Fire Emblem: Akaneia Senki Episode 3 "Mami no shitone" broadcast[^5] |
| October 19 | BS Fire Emblem: Akaneia Senki Episode 4 "Hajimari no toki" broadcast[^5] |
| 1997 | BS Zelda no Densetsu: Inishie no Sekiban (Ancient Stone Tablets) broadcast as SoundLink game[^6] |
| 1997 | Satellaview Guide broadcasts begin[^7] |

### 1998

| Date | Event |
|------|-------|
| 1998 | Ancient Stone Tablets rebroadcast[^6] |

### 1999

| Date | Event |
|------|-------|
| March 28-29 | **SatellaOFF Event 1** -- First known Satellaview fan meetup in Higashi-Shinagawa, Tokyo[^8] |
| April 4 | BS Fire Emblem: Akaneia Senki re-rebroadcast[^5] |
| April 29 | **SatellaOFF Event 2** -- Second meetup in Kameido/Nakano, Tokyo[^9] |
| ~June | Last regular Satellaview broadcasts[^10] |
| Late 1999 | St.GIGA begins winding down Satellaview operations |

### 2000

| Date | Event |
|------|-------|
| Early 2000 | St.GIGA dissolves; Satellaview service officially ends[^11] |

---

## Post-Broadcast Era (2000-2010)

### 2000-2004

| Date | Event |
|------|-------|
| ~2000 | Satellaview History Museum (Kameb) begins documenting the system[^12] |
| 2001 | Pachuka's first known legal trouble[^13] |
| November 2, 1999 | BS Zelda Shrine founded by Con[^14] |
| November 25, 2000 | BS Zelda Shrine relaunches on ZeldaLegends; Duke Serkol joins as co-webmaster[^14] |

### 2005-2007

| Date | Event |
|------|-------|
| March 31, 2005 | End of BS analog broadcasting; St.GIGA transitions to WINJ[^15] |
| 2005 | Pachuka arrested for sexual assault; Sazpaimon takes over X-Cult[^13] |
| 2006 | d4s releases BS Excitebike SoundLink patch -- first Satellaview ROM modification[^16] |
| January 2007 | Satellaview Heaven (Madick) begins blogging[^17] |
| November 2007 | WINJ declared legally bankrupt[^15] |

### 2008-2009

| Date | Event |
|------|-------|
| April 2008 | Satellablog founded by KiddoCabbusses at Blogspot[^18] |
| December 2008 | Satellablog uncovers eBay price-gouging of restored Satellaview content[^19] |
| March 21, 2009 | Satellaview dojin projects documented (BSFE mod, Project Gam)[^20] |
| April 11, 2009 | BS Zelda Shrine Master Quest competition begins[^21] |
| April 2009 | Satellablog relocates to superfamicom.org/blog[^22] |
| August 9, 2009 | Satellaview Soundtracks music restoration project documented[^23] |
| September 17, 2009 | The English Satellaview Wiki founded by KiddoCabbusses[^24] |
| August 26, 2009 | Last Satellablog update by KiddoCabbusses[^25] |

### 2010

| Date | Event |
|------|-------|
| June 1, 2010 | Satellablog investigates BS Dragon Quest ROM origin and ROMar[^26] |
| July 29, 2010 | "Hello Satellaview!" -- first Satellaview homebrew released by LuigiBlood[^27] |
| September 2010 | BS-X Project announced (as "Broadcast Satellaview")[^27] |
| October 21, 2010 | Memory Pack patches (RPG Tsukuru 2, Sound Novel Tsukuru) by LuigiBlood[^28] |
| November 2010 | SFC Mania blog last updated; abandoned[^29] |

---

## Modern Preservation Era (2011-2026)

### 2011-2015

| Date | Event |
|------|-------|
| 2011 | Matthew Callis dumps 22 BS-X SRAM modules -- first successful battery-backed data dumps[^30] |
| October 2012 | snes9x-sx2 released by LuigiBlood[^31] |
| January 2014 | bsnes-sx2 and sat_wave GitHub repos created[^32] |
| 2014+ | sd2snes / FX Pak Pro Satellaview support via RAW broadcast data[^33] |

### 2016

| Date | Event |
|------|-------|
| August 2016 | BS-X Project site redesign; English translation patch v1.3 final[^34] |
| August 2016 | Satellaview Heaven last updated by Madick[^35] |
| October 2, 2016 | Con declares BS Zelda Shrine mission complete (AST MSU-1 project)[^36] |
| November 2016 | bsnes-plus Satellaview integration (LuigiBlood + Revenant)[^37] |

### 2017-2020

| Date | Event |
|------|-------|
| December 2017 | BS-X Project moves to project.satellaview.org; SNES9X official Satellaview support[^34] |
| March 2019 | SatellaWave v0.5.1 released (latest)[^38] |
| 2019 | d4s briefly returns, puts dforce3000.de back online, announces hiatus continues[^39] |
| December 25, 2020 | BS Zelda Shrine last update (Map 1 Week 4 dump from sanmaiwashi/LuigiBlood)[^40] |

### 2024-2026

| Date | Event |
|------|-------|
| 2024 | Satellablog revived; danyl begins posting regular Satellaview dumps[^41] |
| June 2024 | Matthew Callis dumps Chaos Seed Satellaview demo (first ever)[^42] |
| July 8, 2024 | Satellaview+ revival service launched (satellaviewplus.github.io) — simulated live St.GIGA broadcasts with emulation-based client[^48] |
| April 2025 | Last code push to sat_wave repo[^43] |
| January 2026 | LuigiBlood publishes "Satellaview - An Explainer" blog post[^44] |
| 2026 | x-cult.org displays only "IT'S OVER" -- site permanently defunct[^45] |

---

## Unresolved Mysteries

| Mystery | Description |
|---------|-------------|
| **ROMar's Identity** | The source of the first Satellaview ROM leaks was never identified[^46] |
| **BS Dragon Quest Debug ROM** | A unique combined 4-week ROM with debug menu and valid BS-X checksum -- origin unknown[^46] |
| **TestData 10/24** | ROM naming mystery for Yuuko Anai no Houkago no Ousama -- header reads Oct 24 but broadcast was April 24[^47] |
| **Tamori no Picross Dates** | Official Jupiter Corp dates (Aug 6-Sep 2, 1995) contradicted by VHS evidence of broadcasts in April and June 1995[^47] |
| **Lost Broadcasts** | Many SoundLink broadcasts were never recorded or dumped and are lost forever |
