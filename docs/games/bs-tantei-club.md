# BS Tantei Club: Yuki ni Kieru Kako

## Overview

**BS Tantei Club: Yuki ni Kieru Kako** (BS探偵倶楽部 雪に消える過去, "BS Detective Club: The Past That Disappears in the Snow") was a SoundLink mystery adventure game broadcast for the Satellaview. It was part of the Tantei Club series of adventure games.[^1]

## Format

As a SoundLink game, BS Tantei Club featured:
- Radio drama segments advancing the mystery plot
- Interactive detective work synchronized with broadcast narration
- Puzzle-solving segments during broadcast windows
- Voice acting and atmospheric music from St.GIGA

## Restoration

### Project Gam
A fan project named **"Project Gam"** was formed to restore this game. The project aimed to reconstruct the game from available ROM material and broadcast recordings.[^2]

### Music Restoration
Several attempts were made to restore the Satellaview-original music from VHS recordings. The music was spliced from recordings of the original broadcasts and reconstructed into listenable tracks.[^3]

## Current Status

The game exists in partially restored form. Complete restoration is challenging because the game relied heavily on SoundLink features that were synchronized with live radio broadcasts, and not all broadcast recordings have been preserved.
