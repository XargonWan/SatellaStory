# BS Dragon Quest

## Overview

**BS Dragon Quest** was a Satellaview broadcast of Dragon Quest-themed content. It is notable primarily for the existence of a unique **debug ROM** that contains all 4 broadcast weeks combined into a single file with an episode-select menu and a valid BS-X checksum.[^1]

## The Debug ROM

The BS Dragon Quest ROM was part of the stash leaked by Pachuka from ROMar and hosted on BS-X Cult. It is unusual because:

- It contains all 4 weeks in one file with a debug menu
- It has a valid BS-X checksum (highly unusual for hacks or modified ROMs)
- It was NOT modified for emulator compatibility (unlike most early Satellaview ROM hacks)[^2]

This suggests the ROM may have been an internal development or QA build rather than a consumer release.

## Origins

The origin of the BS Dragon Quest ROM is one of the Satellaview's enduring mysteries. The debug features suggest it came from a development environment, but how ROMar obtained it and who created it is unknown. Satellablog author KiddoCabbusses investigated the ROM's origins extensively but was unable to determine more than what Pachuka shared -- and Pachuka was deliberately vague.[^3]

## Current Status

The BS Dragon Quest ROM has been dumped and is preserved. It remains one of the most unusual Satellaview artifacts due to its combined-week format and debug features.
