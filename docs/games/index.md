# Games

## Overview

The Satellaview hosted a diverse library of games and content across multiple formats. This section catalogs known broadcast games with available information.

## Game Categories

### SoundLink Games
Real-time interactive games synchronized with live radio broadcasts. These featured voice acting, narration, music, and live commentary. SoundLink games were inherently ephemeral -- they played during specific broadcast windows and could not be saved.[^1]

**Examples:** BS Zelda: Inishie no Sekiban, BS Fire Emblem: Akaneia Senki, BS Tantei Club, BS F-Zero Grand Prix

### Downloadable Games
Full games that could be downloaded to the Memory Pack and played at any time after broadcast. Some were Satellaview-exclusive; others were modified versions of existing Super Famicom titles.[^2]

### Add-On Data
Additional content or levels for existing Super Famicom games, distributed via satellite.

### Magazines and "Kabe Shinbun"
Downloadable magazines and "wall newspaper" content that provided news, tips, game journalism, and broadcast schedules.[^3]
