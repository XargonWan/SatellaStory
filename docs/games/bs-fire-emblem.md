# BS Fire Emblem: Akaneia Senki

## Overview

**BS Fire Emblem: Akaneia Senki** (BSファイアーエムブレム アカネイア戦記) was a SoundLink game broadcast in 1997. It consisted of 4 episodes combining radio drama segments with tactical RPG gameplay, set in the world of the original Fire Emblem: Shadow Dragon and the Blade of Light.[^1]

## Broadcast Details

| Episode | Title | Broadcast Date |
|---------|-------|----------------|
| Episode 1 | "Pales shugeki" (Attack on Pales) | September 28, 1997 |
| Episode 2 | "Akai kaze RON" (Red Wind Ron) | October 5, 1997 |
| Episode 3 | "Mami no shitone" (Mami's Bed) | October 12, 1997 |
| Episode 4 | "Hajimari no toki" (Time of Beginning) | October 19, 1997 |
| Rebroadcast | All episodes | November 30, 1997 |
| Re-rebroadcast | All episodes | April 4, 1999 onward |

## Format

Each episode was structured as:
1. **Drama segment** -- Radio drama advancing the story
2. **Game system explanation** -- Tutorial narrated by personalities
3. **Map battle** -- Tactical RPG gameplay synchronized with broadcast
4. **Drama segment** -- Conclusion and setup for next episode[^2]

As a SoundLink game, BS Fire Emblem could **not be saved** to the Memory Pack. It existed only during the broadcast window.[^3]

## Connections to Main Series

The game's ending teased **Thracia 776**, which would later be released as a full Super Famicom game. Intelligent Systems (Intsys) acknowledged fan interest in the game in 2009 after community-driven pressure. The game was eventually re-released for the Nintendo DS with updated presentation.[^4]

## Fan Restoration

- **2009:** A mod/mock-up using SRPG Maker 95 was produced[^6]
- **2009:** Fan-driven pressure led to Intelligent Systems commenting on the game[^7]
- **2010:** Music restoration via VHS recordings (shared on Nico Nico Douga)[^8]
- **Subsequent:** Official DS re-release preserved the game

## Documentation

The most detailed documentation of the game comes from **imoko**'s "What is BS Fire Emblem?" page, which confirmed:
- The game was a Sound Link format (radio + gameplay)
- None of the 4 episodes could be saved
- A commercial release of the drama/game elements was considered unlikely by Intsys[^9]
