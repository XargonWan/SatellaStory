# Satellaview / BS-X History Archive

Welcome to the **Satellaview / BS-X History Archive** -- a comprehensive historical documentation project dedicated to preserving the history, lore, and community of the Nintendo Satellaview satellite modem system for the Super Famicom, with special emphasis on **BS-X: Sore wa Namae o Nusumareta Machi no Monogatari** (BS-X: The Story of the Town Whose Name Was Stolen).

## About This Project

This archive is the result of systematic historical research into the Satellaview ecosystem -- its technology, its games, its people, and its community. Every piece of information presented here is sourced from verifiable references including archived web pages, blog posts, forum discussions, official documents, and primary source accounts.

## Scope

- **Satellaview System** -- The satellite modem accessory for the Super Famicom (1995-2000)
- **St.GIGA** -- The radio broadcaster that partnered with Nintendo
- **BS-X Cartridge** -- The operating system/browser cartridge that served as the gateway to all Satellaview content
- **Broadcast Games** -- SoundLink and downloadable games
- **Community** -- The fan communities that formed during and after the service
- **Preservation** -- Restoration projects, ROM dumping, and emulation efforts

## Methodology

All information in this archive is sourced from:

1. Primary sources (archived web pages, forum posts, blog entries, official documentation)
2. Secondary sources (wiki articles, retrospective analyses)
3. Direct community records (IRC logs, email archives, preserved websites)

Each claim is annotated with a reference number linking to the [References](research/references.md) page, which provides the full citation and where applicable, the Wayback Machine archival link.
